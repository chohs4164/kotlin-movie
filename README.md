## 3단계 구현 요약

- [x] H2 데이터베이스와 JDBC 연결을 설정한다.
- [x] 영화 상영 정보를 데이터베이스에 저장한다.
- [x] 영화 제목과 날짜로 상영 정보를 조회한다.
- [x] 예매 좌석 정보를 데이터베이스에 저장한다.
- [x] 저장된 예매 좌석 정보를 다시 조회할 수 있도록 구현한다.
- [x] 프로그램을 다시 실행하더라도 저장된 영화 상영 정보와 예매 정보를 조회할 수 있도록 파일 기반 H2를 적용한다.
- [x] 테스트 환경에서는 In-Memory 기반 H2를 사용해 테스트를 독립적으로 실행한다.
- [x] 좌석 배치의 크기는 고정된 구조를 유지한다.
- [x] 상영관마다 좌석 수나 좌석 배치가 다른 경우는 고려하지 않는다.
- [x] 동일한 좌석에 대한 중복 예매를 데이터베이스 제약 조건으로 방지한다.

## 구현 전략

- 기존 도메인 객체의 변경을 최소화하기 위해 데이터베이스 연동 코드를 infrastructure.db 패키지로 분리한다.
- 상영 정보 저장 및 조회는 JdbcScreeningRepository가 담당한다.
- 예매 좌석 저장 및 복원은 JdbcReservationRepository가 담당한다.
- 애플리케이션 실행 시 SchemaInitializer가 schema.sql을 바탕으로 스키마를 초기화한다.
- 로컬 실행 환경은 파일 기반 H2를 사용해 프로그램 재실행 후에도 데이터가 유지되도록 한다.
- 테스트 환경은 In-Memory H2를 사용해 각 테스트가 독립적으로 실행되도록 한다.
- 핵심 비즈니스 로직은 기존 도메인과 컨트롤러에 유지하고, JDBC 코드는 저장소 계층으로 한정한다.

## 데이터베이스 테스트

- SchemaInitializerTest에서 스키마 초기화와 재호출 가능 여부를 검증한다.
- JdbcScreeningRepositoryTest에서 상영 정보 저장 및 조회를 검증한다.
- JdbcReservationRepositoryTest에서 예매 좌석 저장, 재조회, 중복 예매 예외를 검증한다.

## AI 활용 내역

- JDBC와 H2를 적용하는 과정에서 SQL 문법, UUID 바인딩 방식, 테스트 격리 방법을 점검하는 용도로 AI 도구를 활용했다.
- AI가 제안한 코드를 그대로 사용하지 않고, 현재 프로젝트 구조에 맞도록 repository 분리 방식, 예외 처리 흐름, 테스트 코드를 직접 수정하며 반영했다.
- 이 과정을 통해 파일 기반 H2와 In-Memory H2의 차이, PreparedStatement를 활용한 JDBC 저장/조회 방식, 데이터베이스 제약 조건을 이용한 중복 예매 방지 방식을 학습했다.


# kotlin-movie 1~2단계 구현 요약

## 1단계 — 도메인 설계

영화 예매 시스템의 핵심 도메인을 구현했습니다.

### 사용자 / 결제 관련
- **User** — 포인트 보유
- **Point** — 포인트 정보
- **Payment** — 결제 수단별 할인 적용
- **PointPolicy** — 포인트 계산 정책
- **DiscountPolicy / DiscountCondition** — 무비데이·시간 할인 조건 판단 및 금액 계산

### 영화 / 상영 관련
- **Movie** — 영화 이름, ID
- **Theater** — 상영관 운영시간, 좌석 목록
- **ScreeningMovie** — 상영 시작·종료 시간, Theater·Movie 정보
- **TheaterScheduler** — 스크린별 상영 일정 관리, 상영 가능 여부 검증 및 추가

### 좌석 / 예매 관련
- **Seat** — 행(알파벳)·열(숫자)·등급(S/A/B)·예약 상태(예약 전/중/완료)
- **Seats** — 예매된 좌석 번호 집합
- **Reservation** — 상영 정보(ScreeningMovie) + 좌석 정보
- **Ticket** — 예매 목록(Reservation) + 총 결제 금액

## 2단계 — 입출력 및 컨트롤러

### View
- **OutputView** — 상영 목록, 좌석배치도, 예매 내역 출력
- **InputView** — 예매 시작 여부부터 최종 결제까지 전 단계 입력 처리

### 유효성 처리
- **InputParser** — Y/N, 날짜, 숫자(Int), 좌석, 포인트 파싱
- **InputValidator** — Y/N, 날짜, 숫자, 좌석 입력값 검증

### 컨트롤러
- **MovieController** — 전체 영화 예매 플로우 통합 관리
