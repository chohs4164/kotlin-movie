# kotlin-movie

## 기능 요구 사항

- [] 영화 상영 정보에 대한 데이터베이스 연동과 저장을 실시한다.
- [] 예매 정보에 대한 데이터베이스 연동과 저장을 실시한다.
- [] 프로그램을 다시 실행하더라도 저장된 영화 상영 정보와 예매 정보가 유직되어서 조회할 수 있도록 구현되어 있어야 한다.
- [] 좌석 배치의 크기는 고정적으로 가져간다.
- [] 상영관마다 좌석 수나 좌석 배치가 다른 경우는 고려하지 않는다.


# kotlin-movie 1~2단계 구현 요약

## 1단계 — 도메인 설계

영화 예매 시스템의 핵심 도메인을 구현했습니다.

### 사용자 / 결제 관련
- **User** — 포인트 보유
- **Point** — 포인트 정보
- **Payment** — 결제 수단별 할인 적용
- **PointPolicy** — 포인트 계산 정책
- **DiscountPolicy / DiscountCondition** — 무비데이·시간 할인 조건 판단 및 금액 계산

### 영화 / 상영 관련
- **Movie** — 영화 이름, ID
- **Theater** — 상영관 운영시간, 좌석 목록
- **ScreeningMovie** — 상영 시작·종료 시간, Theater·Movie 정보
- **TheaterScheduler** — 스크린별 상영 일정 관리, 상영 가능 여부 검증 및 추가

### 좌석 / 예매 관련
- **Seat** — 행(알파벳)·열(숫자)·등급(S/A/B)·예약 상태(예약 전/중/완료)
- **Seats** — 예매된 좌석 번호 집합
- **Reservation** — 상영 정보(ScreeningMovie) + 좌석 정보
- **Ticket** — 예매 목록(Reservation) + 총 결제 금액

---

## 2단계 — 입출력 및 컨트롤러

### View
- **OutputView** — 상영 목록, 좌석배치도, 예매 내역 출력
- **InputView** — 예매 시작 여부부터 최종 결제까지 전 단계 입력 처리

### 유효성 처리
- **InputParser** — Y/N, 날짜, 숫자(Int), 좌석, 포인트 파싱
- **InputValidator** — Y/N, 날짜, 숫자, 좌석 입력값 검증

### 컨트롤러
- **MovieController** — 전체 영화 예매 플로우 통합 관리
